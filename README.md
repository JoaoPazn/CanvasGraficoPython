# CanvasGraficoPython
como fazer um simples gráfico usando matpotlib e tkagg como backend.

Caso a primeira parte do código esteja funcionando deve estar mais ou menos parecido com o gráfico "canvas_com_8_eixos" de imagem webp.

Caso a segunda parte do código esteja funcionando deve estar mais ou menos parecido com o gráfico "canva_pizza" de imagem webp.

Caso a terceira parte do código esteja funcionando deve estar mais ou menos parecido com o gráfico "canva_Colunas" de imagem webp.
